Overview

Welcome! Here you will find a tutorial to familiarize yourself with the Chemelt workflow!

1) Data loading and preparation
  1. In this Tutorial we will work with example data published by Hamborg et al., 2020. Please download the NanoDSF example data ACBP.xlsx to your computer. This data is exemplary data of a NanoDSF experiment. It contains multiple thermal denaturation curves of samples with different GuHCl concentrations.
  2. In the tab "1. Import data" upload the data in the Input field under "1. DSF files". You can upload multiple files at once. The tool can handle different file formats (check the User Guide).

  3. The option "Signal" let's you choose different signals captured in the experiment and present in the file. Here we choose both 350 nm and 330 nm. Additionally, the signals can be normalised. The option "Temperature range (ºC)" let's you choose the temperature range which will be analyzed.

  4. In the field "[Denaturant] (M)" you can choose which denaturant concentrations should be included in the fitting. Here, we can exclude the sample with no denaturant. The denaturant concentrations are automatically read from the file but can also be manually changed.

  5. In the field underneath we can see the data as a plot of the signal against temperature.

  6. Here, the curves can be visually inspected to exclude outliers.

2) Function fitting
  1. Under the tab "2a. Settings" we can set the settings for the fitting of the formula to the curves.

  2. The baseline windows are used to obtain initial estimates. We set the native baseline to 15 - 25 °C and the unfolded baseline to 85 - 95 °C. The number of residues is used to provide an initial estimate of the ΔCp parameter. In this case, it should be set to 86. The max number of points per curve is used to reduce the number of points for a faster fitting.
  3. The '2b. Fitting' panel controls the amount of parameters and type of fitting. Briefly, there are three types of models, with local intercepts and local slopes, with local intercepts and global slopes, and with global intercepts and global slopes. The difference between the third and second model is that the third one assumes a linear dependence between the denaturant concentration and the signal, while the second one does not assume any kind of dependence. If the unfolding curves were obtained under the same experimental conditions, such as protein concentration, instrument, laser power, etc., it is recommended to evaluate the fitting methods with global slopes. On the other hand, if the curves were obtained under different experimental conditions, it is advisable to use local slopes. To run a variety of models and compare them, you can choose the 'Compare models' option.

  4. Click on 'Run fitting' to start the fitting process. CheMelt will ask to select the baseline types to be used for the fitting. The baseline types are different mathematical functions that describe the baselines of the unfolding curve. For differential scanning fluorimetry data, we have found that exponential baselines provide good fits for the unfolded baseline and that linear or exponential baselines provide good fits for the native baseline. However, the best choice of baseline types can depend on the specific data and should be evaluated critically. Here, we select 'Linear' and 'Exponential' for the native baseline and 'Exponential' for the unfolded baseline.

3) Analysis
  1. After the fitting is done, the model with the lowest EBIC (extended bayesian information criterion) value is shown in the 'Fitted signal' tab. If the fitted curves do not match the data well, it is recommended to discard that model and evaluate the other models. A Table with a comparison of the different models is shown in the 'Model comparison' tab. In this case, all the models provide similar values for the thermodynamic parameters.

  2. In the Tab "Fitted params" you can find the thermodynamic parameters as well as baseline parameters used to fit the formula to the curve with their respective units. Additionally, you can find the relative error and the boundaries used for fitting. The relative error is an indication of the quality of the fit. While a high relative error indicates an inadequate model, a low error is not proof of an adequate one.
    The resulting thermodynamic parameters should always be critically evaluated, as errors of the fit are possible and they should roughly match expectations. If they reach the boundaries, for example, it can be due to outliers not being accounted for, which skew the results. Fits with physically unreasonable parameters should be discarded.

  3. The results can be exported in the tab "3. Export results". Here the fitted parameters, the original signal and the fitted signal can be exported and downloaded as a CSV file for further analysis.
